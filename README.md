# Stampvale: Photo Date Stamp
Curated product showcase by **Sepideh Javanbakht Dalir** · [arvinify.com](https://www.arvinify.com) · hello@arvinify.com.

Deliberate dates and captions for existing job photos, with separate-copy exports that preserve originals. Native Universal iPhone/iPad utility, iOS15+. Free full-resolution single-photo export; one Lifetime Pro purchase adds batches and reusable presets. No account, subscription, ads, AI or product backend.

Built with Swift, SwiftUI, PHPicker, ImageIO, CoreGraphics, CoreText and StoreKit2. Engineering focuses on strict capture metadata interpretation, explicit missing-date handling, all EXIF orientations, bounded sequential rendering, GPS-free output metadata, cooperative cancellation and verified entitlements. Dates are editable labels, not trusted evidence.

Production source is private. This repository contains curated product/support material only. Release status: **in production; not submitted or available on the App Store as of October16,2026**. No demand, ranking or revenue claim.
